# Digital Relics · 数字遗存

一个关于文物、扫描与数字替身的独立数字艺术项目。

项目的起点来自一次偶然的现场经验。作者在北京市丰台区一处街道社区参加免费课程时，授课老师带来三维扫描仪和一件鸮卣模型，当场演示了扫描过程。一个有体积、有表面的物体，在逐步采集后成为屏幕中的几何与纹理；这次转化触发了对“实体如何成为数据，又如何从数据中重新出现”的持续兴趣。此前，作者已经在网上多次刷到以点云为主体的炫目视觉效果，却一直不知道它们从何而来；直到这次课程，才第一次把那些画面与三维扫描所生成的空间数据联系起来。

当天的课程在演示后便结束了，老师没有布置作业，也没有要求参与者继续完成任何作品。这个网页并非课程任务，而是作者在课后自发延续那次好奇：想亲手完成一个页面，看看扫描数据离开演示现场之后，还能形成怎样的观看经验。

课后查阅资料时，作者了解到也可以通过摄影测量——围绕物体拍摄大量照片——生成三维模型，但实际操作需要相当多的拍摄与整理工作。于是问题变成了：网上是否已经存在扫描完成、可以合法使用的文物数据？沿着这个方向寻找，最终发现了博物馆在 Sketchfab 发布的开放三维资源。项目中的第一件器物鸮尊，正是由此而来。

寻找模型的过程中，作者也发现了与课堂所见鸮卣十分相似的器物数据，但最终没有采用。网络上对鸮卣的数字复现已经很多，继续选择相近形象容易落入重复；于是保留了与鸮卣在形制和视觉特征上区别更明显的鸮尊。它仍然回应了那次课堂经验，却没有直接复制课堂上的对象。

网络上也有爱好者利用博物馆公开照片自行重建文物模型。这些实践很有价值，但当原始照片的角度、数量、尺度与拍摄条件无法核验时，模型中缺失或不可见的表面往往需要由软件推算，可能产生形体、比例和纹理上的偏差。对于以文物为对象的展示，这种不确定性会削弱作品所需要的严谨性。因此，本项目优先采用由收藏机构发布、器物身份与来源可以核对的三维数据。

现有网络作品中，许多数字文物取材于中国境内博物馆。寻找开放资源时，作者恰好发现海外博物馆收藏并发布了一批中国文物模型，于是将选择范围收束到这些身处海外馆藏体系中的中国器物。它们既保留着原有的历史与文化身份，也经历了收藏、研究、数字化和网络传播所形成的另一段路径。

文物从实体经过摄影测量或三维扫描成为数据。几何、纹理和时间留下的痕迹被转换为坐标与颜色；在屏幕上，它们又从器物表面的采样点中重新显形。

这个项目并不试图用炫目的“粒子爆炸”替代文物本身。它更关心扫描所带来的观看距离：我们看到的是原物，还是原物在某一时刻留下的数据记录？数字模型能够保存什么，又会掩盖什么？

## 技术

项目使用 React、Three.js 与 vinext 构建。点云并非空间中的随机粒子，而是从 GLB 模型网格表面按面积采样，并读取模型纹理中的颜色。总览页按照三件器物的实际高度比例呈现，但不会同时加载三个大型模型。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

## 模型来源与授权

三维模型来自博物馆在 Sketchfab 发布的开放资源：

- 鸮尊、水月观音：Minneapolis Institute of Art
- 生肖虎俑：Cleveland Museum of Art

本项目所使用的模型下载页面标示为 **CC0 / Public Domain**。器物名称、年代、材质、尺寸、收藏机构与馆藏编号保留在网页中，用于说明作品来源与语境。

网站代码与视觉编排属于项目作者；文物数字模型的使用遵循各来源页面所标示的授权条件。
